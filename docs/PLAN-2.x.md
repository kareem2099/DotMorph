# DotMorph 2.x plan

2.0 shipped the engine, the wheel, desktop integration and packaging (see `PLAN.md`). The next
releases make it **sound** alive, speak **more languages**, and add four features users will
notice.

| Release | Theme | Contents |
|---|---|---|
| **2.1** | Voice | Sound effects (F), 7 new languages (G) — shipped in 2.2.0 |
| **2.2** | Smarter conversions | "Fit under X MB" (H), OCR (I), transcription (I2) — shipped in 2.2.0 |
| **2.3** | Yours and native | Custom actions (J), native Wayland (K) |

## Phase F: Sound (2.1)

Short, soft UI sounds that match the animations. On by default for the moments that matter,
easy to turn off, and silent where the desktop says "no event sounds".

**How it plays (no new dependency)**
- Qt Multimedia is *not* in PySide6-Essentials (it lives in PySide6-Addons, hundreds of MB with
  a bundled FFmpeg), so it's out.
- **libcanberra through ctypes**, the same approach as librsvg: GNOME's own event-sound library,
  already on practically every desktop. `ca_context_play()` with `CA_PROP_MEDIA_FILENAME`,
  `CA_PROP_EVENT_ID` and `CA_PROP_CANBERRA_VOLUME`. Plain libcanberra does *not* read GNOME's
  "event sounds" switch (only its GTK module does), so DotMorph checks
  `org.gnome.desktop.sound event-sounds` itself.
- Fallback when libcanberra is missing: `pw-play` / `paplay` in the background. Neither: silent,
  never an error.
- New `ui/sound.py`: `Sound.play(name)` exposed to QML as a slot. Plays are non-blocking and
  rate-limited (hover ticks at most every 60 ms).

**The sounds**

| Event | Sound | Default |
|---|---|---|
| Wheel opens | soft "bloom" swoosh, rising | on |
| Hover a sector | tiny tick | **off** (can be tiring) |
| Pick a format | click | on |
| Conversion done | short two-note chime (with the particle burst) | on |
| Conversion failed | low muted "thud" (with the shake) | on |
| Dock / undock at the edge | magnetic "snap" | on |
| Cancel | soft reverse swoosh | on |

- Made for DotMorph, not downloaded: synthesized by a script in the repo (sine/noise envelopes,
  rendered with the stdlib `wave` module, then encoded to OGG by ffmpeg at build time), so the
  licence is clean and they can be regenerated. 16-bit mono, each under 0.5 s, all together
  under 150 KB, packaged in `ui/sounds/`.

**Settings**
- General page: **Sounds** (on / off), **Volume** slider, **Hover ticks** (off by default),
  and a "Play test" button.
- `--mute` for a single run, and `DOTMORPH_SOUND=0`.
- *Reduce motion* doesn't mute sounds (different need), but sounds follow the wheel: no sound
  when the wheel isn't visible (quick actions keep using the notification).

**Tests and packaging**
- A fake libcanberra (ctypes stub) checks which events play, the rate limit and the fallback
  order; the QML tests check every state change calls `play()` once.
- `.deb`: Recommends `libcanberra0`. Arch: optdepends `libcanberra`. AppImage: uses the
  system's libcanberra (it's tied to the sound server), falls back to `pw-play` / `paplay`.

## Phase G: More languages (2.1)

Today: about 130 interface strings in `i18n.py`, English keys plus an Arabic dict, `%1`
placeholders, and no plural support. That won't scale to Russian (one / few / many forms).

**Engine first**
- Move catalogs to `src/dotmorph/locales/<lang>.json` (`ar.json`, `ru.json`, …). English stays
  the source and the fallback.
- **Plurals:** `trn("%n files", n)` with the CLDR rules for each language: one/other (de, it,
  es, pt, tr), one including 0 (fr), one/few/many (ru), zero/one/two/few/many (ar). Arabic
  gets real plurals too, not just one form.
- `RTL_LANGUAGES` stays the source of right-to-left (ar now; fa or he later reuse it for free).

**Languages, first batch (7)**

| Language | Native name | Notes |
|---|---|---|
| Russian | Русский | 3 plural forms; Cyrillic is covered by the current fonts |
| German | Deutsch | long compound words: the main overflow risk on the wheel |
| Italian | Italiano | |
| French | Français | matches dotsuite.dev |
| Spanish | Español | |
| Portuguese (Brazil) | Português (Brasil) | |
| Turkish | Türkçe | dotted / dotless i in upper-case labels |

Later candidates: Persian (RTL), Chinese (needs a CJK font), Japanese, Hindi, Indonesian.

**What gets translated**
- The wheel, options panel, settings window, notifications.
- **New:** the `.desktop` launchers (`Name`, `GenericName`, `Comment`, `Keywords`) and the
  AppStream metainfo summary / description, generated by `build.py assets`. Software centres
  then show DotMorph in the user's language.
- Commands, format names and engine errors stay English (same rule as 2.0).

**Quality gates (tests)**
- Every catalog has every key; placeholders (`%1`, `%n`) match the English source.
- **Overflow check:** load the wheel and every settings page offscreen in each language and
  fail if a label is wider than its sector or row (QML `contentWidth` against the available
  width). German and Russian are the stress tests; labels that don't fit get a shorter
  translation, or shrink and elide.
- The language picker lists languages in their own names, and "System" maps `LANGUAGE` / `LANG`
  variants (`pt_BR`, `de_AT`, `ru_RU.UTF-8`) correctly.

**Who translates**
- First drafts by the maintainer, then native-speaker review through a "Translation" issue
  form on GitHub. Later, Hosted Weblate (free for libre projects) so people can help without
  touching JSON.
- README gets a "Languages" section and a "help translate" line.

## Four more features

### H. "Fit under…" size targets (2.2)
*"Make this video fit Discord / WhatsApp / an email."* The most common reason people
convert at all.
- New tool sector **Fit size** with presets: **8 MB** (Discord), **16 MB** (WhatsApp),
  **25 MB** (Gmail attachment), **Custom…**
- Video: compute the bitrate from the duration, two-pass encode, scale down if needed. Images:
  binary search over quality, then dimensions. PDF: step through Ghostscript presets
  (`/printer` → `/ebook` → `/screen`).
- Never larger than asked; if it can't fit, say so instead of wrecking the file.
- CLI: `dotmorph convert talk.mp4 --fit 8M`.

### I. OCR: text from images and scans (2.2)
- **Image → text** and **scanned PDF → searchable PDF** with Tesseract / `ocrmypdf`, a new backend
  that only appears when they're installed (same registry rules as every other tool).
- The OCR language follows the interface language plus English (`ara+eng`, `rus+eng`…), chosen
  in Settings → Tools, with `doctor` naming the language pack to install.
- Pairs with DotScramble: OCR finds text, DotScramble redacts it.

### I2. Transcription: speech to text (2.2)
Requested in [#4](https://github.com/kareem2099/DotMorph/issues/4): *"drag an audio file and get a
text file or even a copy/paste of the transcribed file."*
- **Fully offline** with **whisper.cpp** (`whisper-cli`): OpenAI's open Whisper models running
  locally, no uploads, no API key. A new backend that only appears when `whisper-cli` and a model
  are installed; `doctor` names the package and the model to download (`base` by default,
  `small` / `medium` for better accuracy).
- **Inputs:** every audio format, and video (the audio track is extracted with ffmpeg first, at
  16 kHz mono, which is what Whisper wants).
- **Outputs:** `.txt`, plus **`.srt` / `.vtt`** subtitles for videos (with timestamps), and a
  **Copy text** action that puts the transcript on the clipboard (wl-copy / xclip) instead of, or
  as well as, writing a file.
- Language: auto-detected, with an override in Settings → Tools (Arabic, English…).
- Progress from whisper's own progress output; cancel kills it like any other tool.
- CLI: `dotmorph convert talk.mp4 --to srt`, `dotmorph convert memo.m4a --to txt --copy`.

### J. Custom actions: plugins without code (2.3)
The "Plugin system" item from the roadmap, in its simplest useful form.
- Drop a TOML file in `~/.config/dotmorph/actions/`:
  ```toml
  name = "Optimize PNG"
  category = "tools"
  inputs = ["png"]
  output = "png"
  command = ["oxipng", "-o", "4", "--out", "{output}", "{input}"]
  ```
- It shows up in the wheel and in `dotmorph formats`, runs through the same engine (work dir,
  progress as elapsed time, cancel, never overwrite) and only appears if its command exists.
- `dotmorph actions list | test NAME FILE`, a Settings page to enable / disable them, and a few
  ready examples in `docs/actions/` (oxipng, yt-dlp audio, ImageMagick montage, `qpdf --linearize`).
- Commands run as argument lists, never through a shell.

### K. Native Wayland (2.3)
Today the wheel runs through XWayland, so it opens centred and isn't a real Wayland surface.
- **KDE Plasma and wlroots compositors (Hyprland, Sway…):** the layer-shell protocol through
  LayerShellQt, so the wheel opens **under the pointer**, stays on top natively, and the edge
  dock becomes a real panel-layer surface.
- **Global shortcut** through the XDG portal `GlobalShortcuts` where it exists (KDE, Hyprland),
  next to the existing GNOME / Xfce setup.
- **GNOME** has no layer-shell: it keeps XWayland, which already works well there.
- Detected at run time; `--platform x11` forces the old path.

**Smaller items to slot in along the way:** ARM64 AppImage (Raspberry Pi, ARM laptops),
"follow the system" as the default theme (AppImageHub's light-theme warning), and a
"recent conversions" list with "show in folder" / "move to trash".
